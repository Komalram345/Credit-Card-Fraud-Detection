# Credit Card Fraud Detection using Machine Learning

## 📌 Project Overview
This project aims to detect fraudulent credit card transactions using Machine Learning techniques. Since fraud cases are rare compared to genuine transactions, the dataset is highly imbalanced. Different classification algorithms and evaluation metrics are used to build an effective fraud detection model.

## 🎯 Objectives
- Detect fraudulent credit card transactions.
- Handle imbalanced datasets.
- Train and evaluate Machine Learning models.
- Reduce false positives while maintaining high fraud detection accuracy.

## 📂 Dataset
- Dataset: Credit Card Fraud Detection Dataset
- Source: Kaggle
- Features: 30 columns (V1–V28, Time, Amount)
- Target:
  - 0 = Genuine Transaction
  - 1 = Fraudulent Transaction
